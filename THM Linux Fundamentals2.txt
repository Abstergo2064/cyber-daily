Theory:
-------
SSH(Secure Shell) Protocol helps create a cryptographic connection between devices and help us remotely access and execute commands on remote desktops or devices.

File Permissions: Different users have different permissions on the same file. There are three sets: Users, Groups and Others.
->Users contains the permissions of the owner of the file.
->Groups contains the permissions of a group.
->Others contains permissions to those who not in both the users and groups

There are three permissions: Read, Write and Execute
Put command ls -l to see who owns the file and what permissions each has.
r=read (4)
w=write (2)
x=execute (1)

Commands to Know:
-----------------
touch -> To create an empty file
file -> To check the file type
man -> shows the manual page of commands or tools
ssh -> To create ssh connection and connect to remote devices
cat -> To print the contents of a file into the terminal
su -> Switch User to another user that exists

Important Directions in your linux filesystem:
----------------------------------------------
-> /etc: Contains all the important system files that your OS needs
eg: /etc/passwd, /etc/shadow
-> /var: Directory where all the variable data is being stored like logs, temp files and other data that are not user specific
eg: /var/log, /var/opt, /var/tmp
-> /root: This is basically the home directory of the root user.
-> /tmp: Stores all the temporary data that is only needed to be accessed one or two times. Kind of works same like the RAM as the data in this directory is cleared when we restart the system.
