THM Linux Fundamentals - 1
---------------------------
First Release of Linux OS is in 1991. It is free and OpenSource.

Important commands needed to complete this room:
-> cd - change directory
-> ls - list the contents in a directory
-> pwd - print working directory 
-> echo - echoes or prints whatever you type into the terminal
-> whoami - To find the user you are logged in as
-> cat - To print the contents of a file into the terminal
-> grep - To search text in a file in a pattern or expression
-> find - To find/locate a file

Operators to know:
1. & -> To run commands in the background
2. > -> to Redirect output into a file. It replaces any data that is already in the file
3. >> -> To redirect output into a file but this operator appends the data with the existing data
4. && -> To combine two commands
