Theory:

1. OSI Model:
--------------
OSI model(Open System Interconnection) is used  to demonstrate the flow of data in computer networks.
It has 7 layers:
-> Application
-> Presentation
-> Session
-> Transport           {Please Do Not Throw Sausage Pizza Away}
-> Network
-> Data Link
-> Physical

Layer 7 - Application layer:
----------------------------
applications/ programs interact with the network to send or receive data in this layer. Data given to the application layer is passed down to Presentation layer as it is.

Layer 6 - Presentation Layer:
-----------------------------
Performs the necessary tasks like compression, encryption etc, to make the data in the standardised format to transmit,then passed down to Session Layer.

Layer 5 - Session Layer:
------------------------
It manages to set up and maintain a connection between the sender and receiver systems. When a session is successfully connected, the data is passed down to Transport Layer.

Layer 4 - Transport Layer:
--------------------------
This layer selects the protocol to be used to transmit the data. Two common protocols are TCP and UDP. Upon selection the data is converted to bit sized pieces for easy transmission.

Layer 3 - Network Layer:
------------------------
This layer works with Logical Addressing i.e Ip addresses. It finds out the destination IP address and stick it to each pieces of the data. Logical Addresses are used to provide order to networks, categorising them and allowing us to properly sort them.

layer 2 - Data Link:
--------------------
This layer deals with the physical addressing i.e MAC addresses. In this layer the MAC address of the destination system is added to the data packets so that it reaches the correct endpoint system.

Layer 1 - Physical:
-------------------
This layer deals with the hardware like cables, routers etc. In this layer the data is transformed to electrical pulses which are transferred or received over the networks. Physical layer converts binary data to signal and vice versa

2. TCP/IP model:
----------------
It's a much more older model. It is most used in the real world networking. Has 4 layers:
-> Application { Application, Presentation and Session }
-> Transport { Transport }
-> Internet { Network }
-> Network Interface { Data Link and Physical }

3. Why These Models are Created?
--------------------------------
Earlier there was no clear standardisation. Different manufacturers followed their own methods. This resulted in compatibility issues.
