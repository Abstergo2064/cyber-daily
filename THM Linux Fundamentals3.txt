Theory:
-------
Processes are programs running in your device managed by the kernel. They have a process ID known as the PID. They are given in an incremental format.
ps command can be used to see processes running in your session. Moreover {ps aux} command can be used to see all the processes running in your device. You can use the {kill} command to kill a process. There are 3 ways in which you can kill a process:
SIGTERM -> Kill the process but lets it finish the clean up
SIGKILL -> Kills the process abruptly
SIGSTOP -> Stop or suspend the process

Systemd is a system and service manager for managing the services and processes in the linux OS. It is the first process that starts when the system boots up.
systemctl is a utility of systemd used to manage the services. It has several options like (start, stop, enable, disable and status)
->systemctl start {service name} - To start a service
->systemctl stop {service name} - To stop a service
->systemctl enable {service name} - To make the service start at bootup
->systemctl start {service name} - To disable it as bootup process

* ctrl+Z can be used to pause a process
* using & operator at the last of a command makes it run in the background
* fg command can be used to bring the background process to foreground 

Cron jobs and Crontab:
-> Cron jobs are scheduled processes that we can specify when to run automatically.
-> Crontab is responsible for facilitating and managing cron jobs.
-> {crontab -e} command can be used to make a new cron job.
-> {crontab -l} command lists all the cron jobs of specified by the user

Repositories in Linux acts as a warehouse that contains a collections of packages/applications. When you type apt install {name}, the package manager search for the apps in these repositories. So it is important to update or add repositories as per your need and to be careful that you do not add unverified repositories.
/etc/apt/sources.list -> contains your repository address
