------------
First make a temporary folder in tmp using - mktemp -d
copy the hexdump file.
1. Revert the hexdump file to original binary -> xxd -r data.txt >data1
2. Check the file type -> file data1
if the file is gzip then rename the file with .gz or if the file is bzip2 file then rename it with .bz2
then based on the file type decompress it 
gzip -> gzip -d data1.gz
bzip2 -> bzip2 -d data1.bz2
then if you find the file type as tar then first rename the file with .tar then:
tar -xf (filename) to extract the file.
do the steps based on the file type until you get human readable ASCII file
